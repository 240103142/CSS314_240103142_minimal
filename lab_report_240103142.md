## 2. Phase 1 — False Sharing & Karp-Flatt

M = 16,000,000 total RMW steps, p = P_phys = 8.

**Table 1A — stride sensitivity**

| stride (words) | separation (B) | median (ms) | IQR (ms) | throughput (Mops/s) |
|---|---|---|---|---|
| 1 | 8 | 566.75 | 14.20 | 28.23 |
| 2 | 16 | 561.11 | 18.84 | 28.51 |
| 4 | 32 | 530.70 | 20.25 | 30.15 |
| 8 | 64 | 521.20 | 14.23 | 30.70 |
| 16 | 128 | 548.88 | 42.16 | 29.15 |
| 32 | 256 | 589.40 | 130.86 | 27.15 |

The largest step between neighbouring strides is 5.4% (at 32 B, not at the reported 128-byte line), but all six medians lie within 13.1% of each other, inside the run-to-run noise (max IQR/median = 22.2%). **On this CPU the false-sharing penalty is not resolvable from pure Python.** Each loop iteration costs about 283 ns of wall time per worker (bigint multiply, masking, ctypes store and bytecode dispatch, plus process spawn), while a cache-line transfer between cores costs on the order of tens of nanoseconds. Apple's cores also absorb repeated stores to the same line in the store buffer, so the coherence traffic is a small fraction of the iteration time and is hidden by interpreter overhead. The expected boundary for this CPU is 128 B (stride = 16).

**Table 1B — Karp-Flatt diagnostic series**

| p | T (s=1) ms | S (s=1) | E (s=1) | e(p) (s=1) | T (s=16) ms | S (s=16) | E (s=16) | e(p) (s=16) |
|---|---|---|---|---|---|---|---|---|
| 1 | 2117.5 | 1.000 | 1.000 | — | 2111.3 | 1.000 | 1.000 | — |
| 2 | 1174.5 | 1.803 | 0.901 | 0.1093 | 1178.0 | 1.792 | 0.896 | 0.1159 |
| 4 | 696.5 | 3.040 | 0.760 | 0.1052 | 668.3 | 3.159 | 0.790 | 0.0887 |
| 8 | 570.5 | 3.712 | 0.464 | 0.1650 | 561.4 | 3.761 | 0.470 | 0.1610 |

**Forensic explanation.** With stride = 1, e(p) goes from 0.1093 to 0.1650 as p grows; with stride = 16 it goes from 0.1159 to 0.1610 (difference at p = 8: +0.0040). The worker code has no serial section, so any e(p) above zero is overhead that behaves like serial work. In theory, under stride = 1 all slots share one or two cache lines: every store needs the line in the Modified state, so the coherence protocol invalidates the other cores' copies and the next writer must fetch it back. Those transfers are serialised on the line and grow with the number of writers, so e(p) should rise faster than with stride = 16, where each slot owns its line. 
In the measured data the two series are almost the same, so false sharing is not the main driver here. The rise of e(p) with p in **both** series comes from (1) process spawn/join cost, which does not shrink with p, and (2) core heterogeneity: at p = 8 half of the workers run on the slower efficiency cores, so the run waits for the slowest worker. The coherence effect is too small to stand out against interpreter overhead, consistent with Table 1A.

## 5. Phase 4 — Scheduling & Load Imbalance

N = 8,000 items, K(i) = 1 + ⌊(i/40)²⌋, p = 8.

| Strategy | T_wall (ms) | IQR (ms) | max t_worker (ms) | mean t_worker (ms) | λ |
|---|---|---|---|---|---|
| Static block | 4060.1 | 159.4 | 3958.6 | 1592.1 | 2.486 |
| Static cyclic | 2380.3 | 23.0 | 2278.5 | 2248.1 | 1.014 |
| Dynamic C=1 | 2449.4 | 24.7 | 2336.2 | 2334.0 | 1.001 |
| Dynamic C=8 | 2469.7 | 71.6 | 2367.9 | 2342.3 | 1.011 |
| Dynamic C=64 | 2547.9 | 10.7 | 2443.5 | 2299.3 | 1.063 |
| Dynamic C=512 | 3072.7 | 39.9 | 2974.0 | 2051.8 | 1.449 |

**Trade-off.** Static block gives λ = 2.49: the last worker owns the heaviest part of the triangle while the others idle at the join. Cyclic interleaving spreads heavy and light items evenly (λ = 1.01). In the dynamic queue, C = 1 balances almost perfectly (λ = 1.001) but every item costs a lock acquire on the shared counter, whose cache line bounces between cores (T_wall = 2449.4 ms). C = 512 claims only ~16 chunks in total, so synchronisation is negligible, but the last chunks are huge and the tail is unbalanced (λ = 1.449, T_wall = 3072.7 ms). The best chunk on this CPU is **C* = 1** (T_wall = 2449.4 ms, λ = 1.001), 1.66× faster than static block.

C = 1 and C = 8 differ by only 20.3 ms, inside the measurement noise, so any chunk in that range is effectively optimal: each item here costs milliseconds of work, so even one lock per item is cheap compared with the work it protects. 
Cyclic static scheduling was slightly faster than the best dynamic run (2380.3 vs 2449.4 ms): the skew K(i) changes smoothly, so round-robin already balances the work (λ = 1.014) with zero synchronisation. Dynamic scheduling would win for irregular skew that cyclic distribution cannot predict, and on a hybrid CPU it also lets fast cores take more items than slow ones.

from dataclasses import dataclass
import multiprocessing as mp
import time
from typing import Callable


@dataclass
class BenchStats:
    min_ms: float
    median_ms: float
    iqr_ms: float


def fnv1a_hash(s: str) -> int:
    h = 14695981039346656037
    for b in s.encode("utf-8"):
        h = ((h ^ b) * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h


def run_benchmark(fn: Callable[[], None], warmup: int = 2, runs: int = 7) -> BenchStats:
    for _ in range(warmup):
        fn()
    samples = []
    for _ in range(runs):
        t0 = time.perf_counter_ns()
        fn()
        samples.append((time.perf_counter_ns() - t0) / 1e6)
    samples.sort()
    med = samples[runs // 2]
    return BenchStats(samples[0], med, samples[(3 * runs) // 4] - samples[runs // 4])


def emit_verify_tag(phase: str, seed: int, m1: float, m2: float) -> str:
    hw = mp.cpu_count()
    sig = fnv1a_hash(f"{phase}|{seed}|{hw}|{m1:.4f}|{m2:.4f}")
    return f"VERIFY_HASH[{phase}]: {sig:016X} (P_log={hw})"

def attach_shm(name: str) -> shared_memory.SharedMemory:
    """Attach to an existing block without registering it with the
    resource tracker (avoids bogus 'leaked shared_memory' warnings on macOS)."""
    try:
        return shared_memory.SharedMemory(name=name, track=False)   # Python 3.13+
    except TypeError:
        shm = shared_memory.SharedMemory(name=name)
        try:
            from multiprocessing import resource_tracker
            resource_tracker.unregister(shm._name, "shared_memory")
        except Exception:
            pass
        return shm


def md_table(headers, rows) -> str:

           "|" + "|".join("---" for _ in headers) + "|"]
    for r in rows:
        out.append("| " + " | ".join(str(x) for x in r) + " |")
    return "\n".join(out)

        return subprocess.run(cmd, shell=True, capture_output=True, text=True, timeout=20).stdout.strip()
    except Exception:
        return ""


def fmt_bytes(n):
    if not n:
        return "n/a"
    n = int(n)
    if n >= 1 << 20:
        return f"{n / (1 << 20):g} MB"
    return f"{n / 1024:g} KB"


def detect_mac():
    def s(key):
        return sh(f"sysctl -n {key} 2>/dev/null")
    h = {
        "cpu_model": s("machdep.cpu.brand_string") or "unknown",
        "P_phys": int(s("hw.physicalcpu") or mp.cpu_count()),
        "P_log": int(s("hw.logicalcpu") or mp.cpu_count()),
        "line_bytes": int(s("hw.cachelinesize") or 64),
        "l1d_bytes": int(s("hw.l1dcachesize") or 0),
        "l2_bytes": int(s("hw.l2cachesize") or 0),
        "l3_bytes": int(s("hw.l3cachesize") or 0),
    }
    # Apple Silicon: perflevel0 = Performance cores, perflevel1 = Efficiency cores
    p0 = s("hw.perflevel0.physicalcpu")
    p1 = s("hw.perflevel1.physicalcpu")
    if p0:
        h["p_cores"] = int(p0)
        h["e_cores"] = int(p1 or 0)
        l1 = s("hw.perflevel0.l1dcachesize")
        l2 = s("hw.perflevel0.l2cachesize")
        if l1:
            h["l1d_bytes"] = int(l1)
        if l2:
            h["l2_bytes"] = int(l2)
        h["e_l1d_bytes"] = int(s("hw.perflevel1.l1dcachesize") or 0)
        h["e_l2_bytes"] = int(s("hw.perflevel1.l2cachesize") or 0)
    h["raw"] = sh("sysctl -n machdep.cpu.brand_string && sysctl hw.physicalcpu hw.logicalcpu "
                  "hw.cachelinesize hw.l1dcachesize hw.l2cachesize hw.l3cachesize "
                  "hw.perflevel0.physicalcpu hw.perflevel1.physicalcpu 2>/dev/null")
    return h


def parse_size(txt):
    m = re.search(r"([\d.]+)\s*(K|M|G)i?B?", txt or "", re.I)
    if not m:
        return 0
    mult = {"K": 1024, "M": 1 << 20, "G": 1 << 30}[m.group(2).upper()]
    return int(float(m.group(1)) * mult)


def detect_linux():
    raw = sh("lscpu")
    def f(key):
        m = re.search(rf"^{key}:\s*(.+)$", raw, re.M)
        return m.group(1).strip() if m else ""
    sockets = int(f("Socket\\(s\\)") or 1)
    cores = int(f("Core\\(s\\) per socket") or mp.cpu_count())
    l1 = parse_size(f("L1d cache"))
    instances = re.search(r"\((\d+) instances\)", f("L1d cache") or "")
    if instances:
        l1 //= int(instances.group(1))
    l2 = parse_size(f("L2 cache"))
    inst2 = re.search(r"\((\d+) instances\)", f("L2 cache") or "")
    if inst2:
        l2 //= int(inst2.group(1))
    return {
        "cpu_model": f("Model name") or "unknown",
        "P_phys": sockets * cores,
        "P_log": mp.cpu_count(),
        "line_bytes": int(sh("getconf LEVEL1_DCACHE_LINESIZE") or 64),
        "l1d_bytes": l1, "l2_bytes": l2, "l3_bytes": parse_size(f("L3 cache")),
        "raw": sh("lscpu | grep -E 'Model name|Socket|Core|Thread|L1d|L2|L3'"),
    }

"""Phase 1 - false sharing / cache-line contention + Karp-Flatt."""
import ctypes
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, p_phys, p_log, attach_shm, log

M_TOTAL = scale(16_000_000, 400_000)
STRIDES = [1, 2, 4, 8, 16, 32]
WARMUP, TIMED = scale(2, 1), scale(7, 3)


def fs_worker(shm_name: str, slot_idx: int, iters: int) -> None:
    shm = attach_shm(shm_name)
    arr = (ctypes.c_uint64 * 512).from_buffer(shm.buf)
    acc = arr[slot_idx]
    mask = 0xFFFFFFFFFFFFFFFF
    mult = 6364136223846793005
    for i in range(iters):
        acc = (acc * mult + (i | 1)) & mask
        arr[slot_idx] = acc            # store to the shared cache line every iteration
    del arr                            # release buffer export before closing
    shm.close()


def make_run(shm_name, p, stride):
    iters = M_TOTAL // p

    def run():
        procs = [mp.Process(target=fs_worker, args=(shm_name, t * stride, iters)) for t in range(p)]
        for pr in procs:
            pr.start()
        for pr in procs:
            pr.join()
    return run


def p_list(plog):
    ps, p = [], 1
    while p < plog:
        ps.append(p)
        p *= 2
    ps.append(plog)
    return ps


def main():
    out = []
    P, PL = p_phys(), p_log()
    shm = shared_memory.SharedMemory(create=True, size=4096)
    try:
        # ---------- Table 1A: stride sweep at p = P_phys ----------
        log(out, f"=== Phase 1A: stride sweep, p = P_phys = {P}, M = {M_TOTAL} ===")
        t1a = []
        for s in STRIDES:
            st = run_benchmark(make_run(shm.name, P, s), WARMUP, TIMED)
            mops = M_TOTAL / (st.median_ms / 1e3) / 1e6
            row = {"stride": s, "bytes": s * 8, "median_ms": st.median_ms,
                   "iqr_ms": st.iqr_ms, "min_ms": st.min_ms, "mops": mops}
            t1a.append(row)
            log(out, f"stride={s:2d} ({s*8:3d} B)  median={st.median_ms:10.2f} ms  "
                     f"IQR={st.iqr_ms:8.2f} ms  {mops:7.2f} Mops/s")

        # biggest relative drop between consecutive strides = coherence boundary
        drops = [(t1a[i - 1]["median_ms"] - t1a[i]["median_ms"]) / t1a[i - 1]["median_ms"]
                 for i in range(1, len(t1a))]
        k = max(range(len(drops)), key=lambda i: drops[i]) + 1
        boundary = t1a[k]["bytes"]
        log(out, f"Largest time drop: {t1a[k-1]['bytes']} B -> {boundary} B "
                 f"({drops[k-1]*100:.1f}%)  => estimated coherence line = {boundary} B")

        # ---------- Table 1B: process scaling with stride 1 and 16 ----------
        t1b = {}
        for s in (1, 16):
            log(out, f"=== Phase 1B: scaling sweep, stride = {s} ===")
            rows, T1 = [], None
            for p in p_list(PL):
                st = run_benchmark(make_run(shm.name, p, s), WARMUP, TIMED)
                if p == 1:
                    T1 = st.median_ms
                S = T1 / st.median_ms
                E = S / p
                e = ((1 / S) - (1 / p)) / (1 - 1 / p) if p >= 2 else None
                rows.append({"p": p, "median_ms": st.median_ms, "iqr_ms": st.iqr_ms,
                             "S": S, "E": E, "e": e})
                log(out, f"p={p:2d}  T={st.median_ms:10.2f} ms  S={S:6.3f}  E={E:6.3f}  "
                         f"e(p)={'-' if e is None else f'{e:.4f}'}")
            t1b[str(s)] = rows
    finally:
        shm.close()
        shm.unlink()

    m1 = next(r["median_ms"] for r in t1a if r["stride"] == 1)
    m16 = next(r["median_ms"] for r in t1a if r["stride"] == 16)
    tag = emit_verify_tag("PHASE1", STUDENT_ID, m1, m16)
    log(out, f"median_ms(stride=1)={m1:.4f}  median_ms(stride=16)={m16:.4f}")
    log(out, tag)
    save_results("phase1", {"P": P, "M": M_TOTAL, "table1a": t1a, "boundary_bytes": boundary,
                            "table1b": t1b, "m1": m1, "m16": m16, "verify": tag, "log": out})


if __name__ == "__main__":
    main()

"""Phase 2 - strong (Amdahl) vs weak (Gustafson) scaling."""
import math
import multiprocessing as mp
import statistics
import time

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, hw, p_phys, p_log, log

N_STRONG = scale(1_200_000, 60_000)
N0_WEAK = scale(200_000, 10_000)
WARMUP, TIMED = scale(1, 0), scale(5, 3)
SERIAL_FRAC = 0.05


def stage_a(n_serial: int) -> float:
    """Strictly serial prefix reduction: 10 math.sin / math.sqrt ops per element."""
    acc = 0.0
    sin, sqrt = math.sin, math.sqrt
    for i in range(n_serial):
        v = 1.0 + i * 1e-5
        v = sin(v); v = sqrt(v * v + 1.0)
        v = sin(v); v = sqrt(v * v + 1.0)
        v = sin(v); v = sqrt(v * v + 1.0)
        v = sin(v); v = sqrt(v * v + 1.0)
        v = sin(v); v = sqrt(v * v + 1.0)
        acc += v
    return acc


def stage_b(rng) -> float:
    """Embarrassingly parallel kernel: 30 FMA + trig ops per element, zero shared writes."""
    start, end = rng
    sin = math.sin
    total = 0.0
    for i in range(start, end):
        x = 1e-6 * (i + 1)
        for k in range(30):
            x = x * 0.9999 + 1e-4 * sin(x + k)
        total += x
    return total


def split(n, p):
    return [(t * n // p, (t + 1) * n // p) for t in range(p)]


def trial_factory(pool, n, p, stage_a_times):
    ranges = split(n, p)
    n_serial = int(SERIAL_FRAC * n)

    def trial():
        t0 = time.perf_counter_ns()
        stage_a(n_serial)
        t1 = time.perf_counter_ns()
        stage_a_times.append((t1 - t0) / 1e6)
        pool.map(stage_b, ranges, chunksize=1)
    return trial


def measure(p, n):
    sa = []
    with mp.Pool(processes=p) as pool:          # created outside the timed region
        pool.map(stage_b, split(p * 2, p))     # make sure every worker is alive
        st = run_benchmark(trial_factory(pool, n, p, sa), WARMUP, TIMED)
    return st, statistics.median(sa[WARMUP:])


def main():
    out = []
    P, PL = p_phys(), p_log()
    h = hw()

    log(out, f"=== Phase 2A: strong scaling, N = {N_STRONG} ===")
    strong = []
    for p in range(1, PL + 1):
        st, ta = measure(p, N_STRONG)
        T1 = strong[0]["T"] if strong else st.median_ms
        S = T1 / st.median_ms
        strong.append({"p": p, "T": st.median_ms, "iqr": st.iqr_ms, "T_A": ta, "S": S, "E": S / p})
        log(out, f"p={p:2d}  T={st.median_ms:10.2f} ms  (StageA {ta:8.2f} ms)  S={S:6.3f}  E={S/p:6.3f}")

    log(out, f"=== Phase 2B: weak scaling, N0 = {N0_WEAK} per worker ===")
    weak = []
    for p in range(1, PL + 1):
        st, ta = measure(p, p * N0_WEAK)
        T1 = weak[0]["T"] if weak else st.median_ms
        alpha = ta / st.median_ms
        SG = p - alpha * (p - 1)
        weak.append({"p": p, "N": p * N0_WEAK, "T": st.median_ms, "iqr": st.iqr_ms, "T_A": ta,
                     "E_weak": T1 / st.median_ms, "alpha": alpha, "S_G": SG})
        log(out, f"p={p:2d}  N={p*N0_WEAK:9d}  T={st.median_ms:10.2f} ms  E_weak={T1/st.median_ms:6.3f}  "
                 f"alpha={alpha:.4f}  S_G={SG:6.3f}")

    # Amdahl analysis
    s = strong[0]["T_A"] / strong[0]["T"]
    S_inf = 1 / s
    S_amdahl_PL = 1 / (s + (1 - s) / PL)
    S_obs_PL = strong[-1]["S"]
    log(out, f"serial fraction s = {s:.4f}  S_inf = {S_inf:.3f}  "
             f"Amdahl S({PL}) = {S_amdahl_PL:.3f}  observed S({PL}) = {S_obs_PL:.3f}")

    # Inflection: P-core -> E-core cluster on Apple Silicon, or P_phys -> SMT siblings
    if h.get("p_cores") and h.get("e_cores"):
        B, kind = int(h["p_cores"]), "P-core -> E-core cluster"
    elif PL > P:
        B, kind = P, "physical -> SMT/Hyper-Threading"
    else:
        B, kind = None, "none (P_log == P_phys, homogeneous)"
    dS = [None] + [strong[i]["S"] - strong[i - 1]["S"] for i in range(1, len(strong))]
    infl = {"boundary": B, "kind": kind}
    if B and B < PL:
        before = [d for i, d in enumerate(dS) if d is not None and strong[i]["p"] <= B]
        after = [d for i, d in enumerate(dS) if d is not None and strong[i]["p"] > B]
        mb, ma = statistics.mean(before), statistics.mean(after)
        infl.update({"mean_dS_before": mb, "mean_dS_after": ma,
                     "drop_pct": (1 - ma / mb) * 100 if mb else 0.0,
                     "dS_at_B": dS[B - 1] if B >= 2 else None, "dS_at_B1": dS[B]})
        log(out, f"Inflection at p={B}->{B+1} ({kind}): mean marginal dS/worker "
                 f"{mb:.3f} -> {ma:.3f}  (drop {infl['drop_pct']:.1f}%)")
    else:
        log(out, f"No architectural boundary inside 1..{PL}: {kind}")

    S_G_PL = weak[-1]["S_G"]
    tag = emit_verify_tag("PHASE2", STUDENT_ID, S_obs_PL, S_G_PL)
    log(out, f"S_strong(P_log)={S_obs_PL:.4f}  S_Gustafson(P_log)={S_G_PL:.4f}")
    log(out, tag)
    save_results("phase2", {"N_strong": N_STRONG, "N0": N0_WEAK, "strong": strong, "weak": weak,
                            "dS": dS, "s": s, "S_inf": S_inf, "S_amdahl_PL": S_amdahl_PL,
                            "S_obs_PL": S_obs_PL, "S_G_PL": S_G_PL, "inflection": infl,
                            "verify": tag, "log": out})


if __name__ == "__main__":
    main()

"""Phase 3 - empirical roofline (3A) + progressive cache-blocked GEMM (3B)."""
import multiprocessing as mp
from array import array
from multiprocessing import shared_memory, util

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, hw, p_phys, attach_shm, log

BUF_BYTES = scale(64 * 10**6, 8 * 10**6)        # two 64 MB buffers = 128 MB total
FLOPS_PER_WORKER = scale(60_000_000, 3_000_000)
N = scale(256, 64)
BS_LIST = [8, 16, 32, 64, 96, 128]

_g = {}


def _release_worker_views():
    """Release memoryview exports before interpreter shutdown (avoids BufferError on exit)."""
    for k in ("A", "B", "C", "mva", "mvb"):
        v = _g.pop(k, None)
        if isinstance(v, memoryview) and k in ("A", "B", "C"):
            v.release()
    for k in [k for k in _g if k.startswith("shm")]:
        _g.pop(k).close()


# ----------------------------------------------------------------- Part 3A
def init_bw(name_a, name_b):
    _g["shmA"] = attach_shm(name_a)
    _g["shmB"] = attach_shm(name_b)
    _g["mva"] = _g["shmA"].buf
    _g["mvb"] = _g["shmB"].buf
    util.Finalize(None, _release_worker_views, exitpriority=10)


def copy_slice(rng):
    s, e = rng
    _g["mva"][s:e] = _g["mvb"][s:e]          # native memcpy: 1 read + 1 write per byte
    return e - s


def fma_worker(iters):
    a, b = 0.999999, 1e-6
    x0 = x1 = x2 = x3 = x4 = x5 = x6 = x7 = 0.1
    x8 = x9 = x10 = x11 = x12 = x13 = x14 = x15 = 0.2
    for _ in range(iters):                    # 16 FMAs x 2 FLOPs = 32 FLOPs / iteration
        x0 = x0 * a + b; x1 = x1 * a + b; x2 = x2 * a + b; x3 = x3 * a + b
        x4 = x4 * a + b; x5 = x5 * a + b; x6 = x6 * a + b; x7 = x7 * a + b
        x8 = x8 * a + b; x9 = x9 * a + b; x10 = x10 * a + b; x11 = x11 * a + b
        x12 = x12 * a + b; x13 = x13 * a + b; x14 = x14 * a + b; x15 = x15 * a + b
    return x0 + x1 + x2 + x3 + x4 + x5 + x6 + x7 + x8 + x9 + x10 + x11 + x12 + x13 + x14 + x15


def roofline(out, P):
    A = shared_memory.SharedMemory(create=True, size=BUF_BYTES)
    B = shared_memory.SharedMemory(create=True, size=BUF_BYTES)
    try:
        B.buf[:BUF_BYTES] = bytes(range(256)) * (BUF_BYTES // 256) + bytes(BUF_BYTES % 256)
        ranges = [(t * BUF_BYTES // P, (t + 1) * BUF_BYTES // P) for t in range(P)]
        with mp.Pool(P, initializer=init_bw, initargs=(A.name, B.name)) as pool:
            pool.map(copy_slice, ranges)      # touch pages once
            st = run_benchmark(lambda: pool.map(copy_slice, ranges, chunksize=1),
                               scale(2, 1), scale(7, 3))
        assert bytes(A.buf[:4096]) == bytes(B.buf[:4096])
    finally:
        for s in (A, B):
            s.close()
            s.unlink()
    bw = 2 * BUF_BYTES / ((st.median_ms / 1e3) * 1e9)
    log(out, f"=== Phase 3A: roofline (P_phys = {P}) ===")
    log(out, f"Copy {BUF_BYTES/1e6:.0f} MB (x2 buffers): median {st.median_ms:.3f} ms, "
             f"IQR {st.iqr_ms:.3f} ms  => BW_sustained = {bw:.3f} GB/s")

    iters = FLOPS_PER_WORKER // 32
    with mp.Pool(P) as pool:
        pool.map(fma_worker, [1000] * P)
        st2 = run_benchmark(lambda: pool.map(fma_worker, [iters] * P, chunksize=1), scale(1, 0), scale(5, 3))
    gflops = P * iters * 32 / ((st2.median_ms / 1e3) * 1e9)
    log(out, f"FMA loop {P} x {iters*32:.3g} FLOPs: median {st2.median_ms:.2f} ms  "
             f"=> P_sustained = {gflops:.4f} GFLOP/s")
    ridge = gflops / bw
    log(out, f"Ridge point I* = P/BW = {ridge:.6f} FLOP/Byte")
    return {"buf_bytes": BUF_BYTES, "bw_ms": st.median_ms, "bw_iqr": st.iqr_ms, "BW": bw,
            "fma_ms": st2.median_ms, "P_sust": gflops, "ridge": ridge}


# ----------------------------------------------------------------- Part 3B
def init_gemm(na, nb, nc, n):
    for k, nm in (("A", na), ("B", nb), ("C", nc)):
        shm = attach_shm(nm)
        _g["shm" + k] = shm
        _g[k] = shm.buf.cast("d")
    _g["N"] = n
    util.Finalize(None, _release_worker_views, exitpriority=10)


def v1_naive(r0, r1):
    A, B, C, n = _g["A"], _g["B"], _g["C"], _g["N"]
    for i in range(r0, r1):
        io = i * n
        for j in range(n):
            dot = 0.0
            for k in range(n):
                dot += A[io + k] * B[k * n + j]       # B walked with stride N
            C[io + j] = dot


def v2_ikj(r0, r1):
    A, B, C, n = _g["A"], _g["B"], _g["C"], _g["N"]
    for i in range(r0, r1):
        io = i * n
        crow = [0.0] * n
        for k in range(n):
            aik = A[io + k]                           # hoisted a_ik
            brow = B[k * n:(k + 1) * n]               # contiguous row slice (zero-copy view)
            for j in range(n):
                crow[j] += aik * brow[j]              # unit stride
        C[io:io + n] = array("d", crow)


def v3_blocked(r0, r1, bs):
    A, B, C, n = _g["A"], _g["B"], _g["C"], _g["N"]
    cloc = [[0.0] * n for _ in range(r1 - r0)]
    for ii in range(r0, r1, bs):
        imax = min(ii + bs, r1)
        for jj in range(0, n, bs):
            jmax = min(jj + bs, n)
            for kk in range(0, n, bs):
                kmax = min(kk + bs, n)
                for i in range(ii, imax):              # micro-kernel order i-k-j
                    crow = cloc[i - r0]
                    io = i * n
                    for k in range(kk, kmax):
                        aik = A[io + k]                # hoisted out of j-loop
                        brow = B[k * n + jj:k * n + jmax]
                        j = jj
                        for b in brow:
                            crow[j] += aik * b
                            j += 1
    for i in range(r0, r1):
        C[i * n:(i + 1) * n] = array("d", cloc[i - r0])


def task(args):
    variant, r0, r1, bs = args
    if variant == 1:
        v1_naive(r0, r1)
    elif variant == 2:
        v2_ikj(r0, r1)
    else:
        v3_blocked(r0, r1, bs)
    return r1 - r0

"""Phase 4 - skewed workload: static block vs cyclic vs dynamic chunk queue."""
import math
import multiprocessing as mp
import time

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, p_phys, log

N = scale(8_000, 2_000)
CHUNKS = [1, 8, 64, 512]
WARMUP, TIMED = scale(1, 0), scale(5, 1)


def item(i: int) -> float:
    k = 1 + int((i / 40) ** 2)            # K(i) = 1 + floor((i/40)^2)
    x = 0.5 + (i % 7) * 0.01
    sin, cos, sqrt = math.sin, math.cos, math.sqrt
    for _ in range(k):
        x = sqrt(abs(sin(x) + cos(x)) + 0.5)
    return x


def w_block(t, p, n, times):
    t0 = time.perf_counter_ns()
    for i in range(t * n // p, (t + 1) * n // p):
        item(i)
    times[t] = (time.perf_counter_ns() - t0) / 1e6


def w_cyclic(t, p, n, times):
    t0 = time.perf_counter_ns()
    for i in range(t, n, p):
        item(i)
    times[t] = (time.perf_counter_ns() - t0) / 1e6


def w_dynamic(t, p, n, times, counter, chunk):
    t0 = time.perf_counter_ns()
    while True:
        with counter.get_lock():          # synchronised claim on the shared index
            start = counter.value
            counter.value = start + chunk
        if start >= n:
            break
        for i in range(start, min(start + chunk, n)):
            item(i)
    times[t] = (time.perf_counter_ns() - t0) / 1e6


def run_strategy(p, kind, chunk=0):
    records = []

    def once():
        times = mp.Array("d", p)
        if kind == "dynamic":
            counter = mp.Value("i", 0)
            procs = [mp.Process(target=w_dynamic, args=(t, p, N, times, counter, chunk)) for t in range(p)]
        else:
            fn = w_block if kind == "block" else w_cyclic
            procs = [mp.Process(target=fn, args=(t, p, N, times)) for t in range(p)]
        t0 = time.perf_counter_ns()
        for pr in procs:
            pr.start()
        for pr in procs:
            pr.join()
        wall = (time.perf_counter_ns() - t0) / 1e6
        records.append((wall, list(times)))

    st = run_benchmark(once, WARMUP, TIMED)
    timed = records[WARMUP:]
    wall, tw = min(timed, key=lambda r: abs(r[0] - st.median_ms))   # run nearest the median
    lam = max(tw) / (sum(tw) / p)
    return {"T_wall": st.median_ms, "iqr": st.iqr_ms, "t_worker": tw, "lambda": lam}


def main():
    out = []
    P = p_phys()
    work = [1 + int((i / 40) ** 2) for i in range(N)]
    log(out, f"=== Phase 4: skewed workload N = {N}, p = P_phys = {P} ===")
    log(out, f"K(0) = {work[0]}, K(N-1) = {work[-1]}, total iterations = {sum(work)}")

    rows = []
    for label, kind, c in ([("Static block", "block", 0), ("Static cyclic", "cyclic", 0)] +
                           [(f"Dynamic C={c}", "dynamic", c) for c in CHUNKS]):
        r = run_strategy(P, kind, c)
        r.update({"label": label, "kind": kind, "chunk": c})
        rows.append(r)
        log(out, f"{label:16s} T_wall={r['T_wall']:10.2f} ms  IQR={r['iqr']:7.2f}  lambda={r['lambda']:.3f}  "
                 f"t_worker=[{', '.join(f'{x:.0f}' for x in r['t_worker'])}]")

    dyn = [r for r in rows if r["kind"] == "dynamic"]
    best = min(dyn, key=lambda r: r["T_wall"])
    c_star = best["chunk"]
    T1 = rows[0]["T_wall"]
    log(out, f"C* = {c_star}  speedup over static block = {T1 / best['T_wall']:.2f}x")
    tag = emit_verify_tag("PHASE4", STUDENT_ID, T1, best["T_wall"])
    log(out, f"T_wall(Strategy 1)={T1:.4f}  T_wall(Strategy 3, C*)={best['T_wall']:.4f}")
    log(out, tag)
    save_results("phase4", {"N": N, "P": P, "rows": rows, "c_star": c_star, "verify": tag, "log": out})


if __name__ == "__main__":
    main()

    else:
